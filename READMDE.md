# python ATM project

a simple ATM simulation program buit with python.

## Description

This program simulates basic ATM operations. Users must enter the correct PIN to access the ATM menu. After successful authentication, they can check their balance, deposit money, withdraw money, and view their account details.

## Features

1. PIN authentication
2. Maximum of 3 PIN attempts 
3. Check account balance
4. Deposit money
5. Withdraw money
6. Prevent withdrawals that exceed the available balance
7. Display account details
8. Validate amount input
9. Exit the program

## How to Run

1. install python 3
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command: python main.py


## About

This project was created  as a python practice project to learn functions, dictionaries, loops, conditional statements, and error handling.

NOTE: This is a practice  ATM simulation. It usus sample account information ana a PIM stored directly in the code. it is not connected to a real bank and should not be used for financial transactions.
